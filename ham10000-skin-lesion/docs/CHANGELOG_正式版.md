# 期末實驗正式版：合併紀錄（交第二輪審查）

合併來源：Claude 原版與 ChatGPT 審查修正版。以 ChatGPT 修正版為基礎，再加入下列修改。組長已確認 E3b 加入模型 C，以及 E4 的排除規則與敏感度分析。

## 一、沿用 ChatGPT 修正版的部分

- 00：HAM 張數、影像編號唯一、病灶診斷一致、ISIC 標籤單一的檢查，以及 `e4_audit_status.json`
- 01／02：預測檔附影像編號、續跑時紀錄與檔案不一致即停止、驗證集 macro-F1 固定七類
- 02：回合數試跑不產生測試集與外部資料預測

## 二、修改的部分

| 項目 | 修改 | 理由 |
|---|---|---|
| 試跑的 early stopping | 恢復，與正式訓練相同 | 試跑若不提前停止，看到的後段進步在正式訓練中可能跑不到，兩者規則需一致 |
| 外部資料預測 | 所有模型預測全部 1,705 張，排除名單在分析時依影像編號套用 | 修正版只預測當下保留的影像，排除名單一改就要重跑。現在 01／02 不再因 E4 稽核而停止訓練，稽核改在 E4 分析時檢查 |
| 預測對齊 | 新增 `pred_for`／`prob_for`，分析一律依影像編號取值，缺少即報錯 | 修正版有存編號，但分析仍依順序對應 |
| 配對比較 | 移除「判讀」欄，改列各種子差值、平均 ± 標準差、差值為正的種子數 | 依第一輪審查意見，修正版程式仍保留該欄 |
| E3b | 新增模型 C：從模型 A 訓練集移除與測試集無關的整個病灶，各類別移除張數與 B 相同，優先抽取多張影像的病灶。主要比較為 C − B，A − B 為輔助 | 解決 B 訓練量與組成不同的混淆。配對結果輸出於 `E3b_control_matching.csv` |
| E3b 驗證集 | A、B、C 共用原驗證集，不另外清理 | 三者相同，不造成組間差異。驗證集含測試病灶只會讓 B 稍微受益，偏差方向是低估洩漏 |
| E3b 分群類別 | 「病灶出現過／未出現過」兩群只用兩群都有的類別計算 macro-F1，並列類別數 | 讓兩群的 C − B 可以並列比較 |
| 00 近似重複 | pHash 只作候選，SSIM ≥ 0.90 才確認為同一照片，並量化 pHash 的漏抓與誤報 | 真實資料中 pHash ≤ 6 的 1,690 組只有 156 組同病灶，同病灶的影像組合至少有 2,545 組，且 110 張 ISIC 候選人工檢視未見同一照片 |
| E4 排除 | 影像編號相同、IL 病灶編號相同，或 pHash ≤ 6 且 SSIM ≥ 0.90。另輸出排除全部 pHash 候選的敏感度分析 | 只因 pHash 排除會移除 97 張痣，改變外部資料組成 |
| IL 編號有效性 | 00 自動檢查 HAM 病灶編號與封存庫 IL 編號一對一，未通過則 E4 分析暫停 | Colab 實測為 7,470 對 7,470 一對一，ISIC 2018 與 HAM10000 的 IL 重疊為 0 |

## 三、目前的真實資料結果（00 已在 Colab 執行）

- HAM10000：10,015 張、7,470 個病灶。IL 編號對應一對一。
- ISIC 2018：1,705 張，影像編號重疊 0、IL 病灶編號重疊 0、pHash 候選 110 張。
- 封存庫 attribution 判定 1,705 張全部為「same」，無法以 attribution 分出 316 張不同機構影像，E4 只回報整體結果。

## 四、測試狀態

- 以模擬小資料（384 張 HAM、110 張 ISIC，含刻意放入的同一照片與同 IL 病灶）完整執行 00、01、02。
- 00：刻意放入的同一照片 SSIM 0.996 被排除，同 IL 病灶被排除，其餘 pHash 候選保留。
- 01：40 次訓練完成，模型 C 每類移除張數與 B 完全相同。
- 02：試跑、40 次訓練、E1～E4 分析與 Grad-CAM 完成。
- 尚未在真實資料上執行 01、02。

## 五、請審查的重點

1. `control_removal()` 的配對邏輯是否合理，有無造成 B 與 C 其他系統性差異。
2. E3b 分群改用「兩群共同類別」是否恰當。
3. E4 排除規則與敏感度分析是否足以支撐「有限度外部驗證」的說法。
4. 依影像編號對齊的實作是否完整涵蓋所有分析。

# 第二輪審查後的修改（v2）

## 對 A 類問題的處理

| 項目 | 處理 | 說明 |
|---|---|---|
| A1 驗證集與測試集共享病灶 | **採納** | 模型 B、C 選擇回合用的驗證集，改為移除與測試集同病灶影像後的版本，並加入斷言檢查。模型 A 沿用 E3 的原驗證集，僅作參考，主要比較 C − B 的兩個模型使用同一份乾淨驗證集，不增加訓練次數。「偏差只會低估」的說法已自 Word 與筆記本移除 |
| A2 模型 C 配對失敗仍繼續 | **採納** | 任何種子、任何類別的移除影像數不相等即 `assert` 停止 |
| A3 C − B 的結論界線 | **採納** | 定位為「控制訓練影像數與類別組成後的比較」，不視為純粹因果效果。`E3b_control_matching.csv` 新增 B、C 移除的病灶數、C 來自多張影像病灶的比例、移除病灶也在驗證集的數量 |
| A4 HAM 跨集合重複 | **採納，且真實資料已有結果** | 見下 |

## A4 的真實資料結果與處理

新版 00 在 Colab 的結果：1,534 組 pHash 候選中，SSIM ≥ 0.90 只有 1 組（ISIC_0025226／HAM_0004919 與 ISIC_0030074／HAM_0000140，SSIM 0.952），看圖確認為同一病灶（毛髮與周圍色素斑位置相同，僅色調不同），在種子 42 跨訓練集與測試集。SSIM 次高的組合（0.897、0.895）看圖為不同病灶。

處理：01、02 新增 `LESION_MERGE`，切分前將這兩個病灶編號合併為同一病灶，原編號保留於 `lesion_id_original`。若 00 輸出的 `ham_confirmed_same_photo.csv` 與 `LESION_MERGE` 不一致，程式會停止，要求人工確認後更新。

## 對 B 類問題的處理

- **已修改**：B1（沒有預測為黑色素瘤時 Precision 記為 0）、B2（輸出每個種子實際使用的類別清單）、B4／B5（00 加註 pHash 量化的意義與 SSIM 門檻的性質，Word 同步修改）、B6（E4 固定七類並輸出各類影像數）、B9／B10（寫入 Word 研究方法）。
- **留到分析與報告階段**：B3（圖的呈現方式）、B7／B8／B12（版本指紋與完整性檢查）、B11（混淆矩陣圖註）。這些不影響訓練，可用已保存的預測重新計算。

## ISIC 2018 的真實資料結果

影像編號重疊 0、IL 病灶編號重疊 0、pHash 候選 110 張中 SSIM ≥ 0.90 者 1 張（0.909，依預設規則排除，待人工複核）。正式保留 1,704 張，敏感度分析保留 1,595 張。封存庫 attribution 全部為同一值，無法區分來源。
